## 📋 QUICK SETUP (5 MINUTES)

### 1. Go to Google Search Console
```
https://search.google.com/search-console
```

### 2. Verify Domain
- Click "Add property"
- Enter: `https://galatfamily.in`
- Choose "HTML meta tag" verification
- Add to `/app/layout.tsx` in metadata
- Deploy
- Wait 24-48 hours
- Click "Verify"

### 3. Submit Sitemap
- In left sidebar: "Sitemaps"
- Click "Add a new sitemap"
- Enter: `galatfamily.in/sitemap.xml` (no https://)
- Click "Submit"

## 🔧 TROUBLESHOOTING

| Problem | Fix |
|---------|-----|
| Verification not working | Wait 48 hours, check meta tag in HTML |
| Sitemap not found | Check if `galatfamily.in/sitemap.xml` loads in browser |
| Pages not indexed | Check "URL Inspection" tool - see why Google skipped it |
| Slow crawl rate | Check Core Web Vitals - may be too slow |
| No traffic after ranking | Improve title/meta description to boost CTR |
