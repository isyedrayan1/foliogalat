## Support & Troubleshooting

### If indexing is slow
1. Check Google Search Console
2. Verify sitemap is valid
3. Check for crawl errors
4. Ensure pages aren't noindexed
5. Submit manual URL to Google

### If rankings don't improve
1. Verify target keywords are realistic
2. Check competitor content
3. Improve on-page factors (H1, internal links)
4. Build more content (more signals)
5. Ensure content is unique and valuable

### If traffic drops
1. Check for algorithm updates
2. Monitor Core Web Vitals
3. Check for new crawl errors
4. Verify no accidental noindex
5. Review recent content changes
